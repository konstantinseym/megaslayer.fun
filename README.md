megaslayer.fun is an educational full-stack project for an anonymous imageboard platform.

The project includes a React frontend, Express backend, and PostgreSQL database.  
It is currently in an early MVP / partially abandoned state and may be continued in the future.

STATUS
Work in progress.  
The project was built primarily for learning and experimentation with full-stack architecture, API design, database interactions, and deployment to VPS.

STACK
- React
- Express.js
- PostgreSQL
- Node.js

FEATURES
- frontend + backend architecture
- REST API experiments
- PostgreSQL integration
- VPS-oriented deployment approach
- MVP imageboard functionality experiments

NOTES
This repository is not production-ready.  
Some parts are incomplete, unstable, or require refactoring.

PLANS
- improve overall architecture
- refine database structure
- finish missing MVP functionality
- improve deployment and stability
